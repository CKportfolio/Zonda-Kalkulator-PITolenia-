# ZondaPIT v1.0 — Windows x64

Historyczny build aplikacji Zonda PIT-38 Calculator.

## Zawartość paczki

- `ZondaPIT.exe`
- pusty katalog `_wrzuc_raport/`

Aby uruchomić aplikację, umieść zgodne historyczne eksporty Zonda OPS/TRD w katalogu `_wrzuc_raport`, a następnie uruchom `ZondaPIT.exe`.

**Dane transakcyjne nie są częścią tej paczki.**
